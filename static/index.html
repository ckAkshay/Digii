HOW VERIFICATION WORKS

You don't have to take the record's word for it.

01

A code, not a signature

The instructor projects a six-digit code that changes every 30 seconds. A student has to be in the room, right now, to enter the current one.

02

Every action is a signed event

Check-ins, disputes, resolutions, and corrections are never edited in place. Each one is appended as its own event, and the full history stays visible.

03

Each event locks in the one before it

Every event stores a hash of itself plus the hash of the event before it. Change anything in the past, and every hash after it stops matching.

04

Anyone can check the math

Students keep a signed receipt; instructors and students can both replay the chain and confirm nothing in it was altered - no one has to trust a screenshot.
